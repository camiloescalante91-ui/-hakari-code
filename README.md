## 🛠️ Stack Tecnológico

- **Frontend**: Next.js 14 + React 18 + TypeScript
- **Animaciones**: GSAP + Three.js
- **Estilos**: Tailwind CSS
- **Multiidioma**: next-intl
- **Hosting**: Vercel

## 🚀 Desarrollo Local

```bash
npm install
npm run dev
```

Abre [http://localhost:3000](http://localhost:3000) en tu navegador.

## 📦 Build para Producción

```bash
npm run build
npm run start
```
